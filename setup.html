RUN

Seven steps

Get the APK

Download from the releases link above on your device. Browsers may warn about non-Play files; the panel ships as a direct APK by design.

Allow the install

Settings → Apps → Special access → Install unknown apps: allow your browser or file manager. The dex is Virbox-packed, so Play Protect may flag the unknown signature — scan once, then accept with Install anyway.

Grant root or start Shizuku

Open the panel; grant the superuser prompt from Magisk/KernelSU when asked (the injector needs UID 0). No root but rooted-adjacent setup? Start Shizuku wireless debugging — the build carries the Shizuku provider.

Allow the overlay

When the panel asks, enable Display over other apps. The floating panel renders on layer 2003 via SYSTEM_ALERT_WINDOW; without it the in-game HUD cannot appear.

Activate your key

Type your license key and hit activate. The app runs the exact request documented on the Key System page: INVALID means unknown, BLOCKED means revoked, EXPIRED means past expiresAt, ERROR means network or locked rules — retry on stable internet.

Launch the overlay

Start a match, then open the floating panel from the notification or launcher service. First attach prints the boot log: PID hook, libil2cpp.so base resolve, offset patch, ESP override.

Tune config.json

Adjust FOV, smoothing and module toggles in the panel config (defaults below). Values apply on relaunch of the overlay.
